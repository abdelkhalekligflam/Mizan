# Mizan

Premium mobile-first personal finance app. Next.js App Router, TypeScript, Tailwind CSS v4.

## Start

```bash
npm install
npm run dev
```

Visit http://localhost:3000.

## Current phase

- Responsive finance dashboard, transactions, spending breakdown, mobile navigation.
- **Prototype only**: data is kept in React state and disappears on refresh. Do not enter real financial data yet.
- Supabase authentication, secure persistence, budgets, and savings goals are upcoming.

## Deployment

Import this GitHub repository into Vercel as a Next.js project. No environment variables are needed for the UI prototype.
